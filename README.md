# Ender's Vein Mine

## Project Overview
Ender's Vein Mine is a Minecraft mod that adds a powerful vein mining tool, allowing players to instantly mine entire ore veins with a single click. Designed for both Fabric and NeoForge platforms, it enhances mining efficiency and gameplay experience.

## Features
- Single-click vein mining for all ore types.
- Supports both Fabric and NeoForge mod loaders.
- Configurable keybindings and mining radius.
- Compatible with Minecraft versions 1.20.1, 1.21.1, 1.21.11, 1.21.2, and 1.22.

## Installation
1. Download the latest release JAR from the [Releases page](https://www.curseforge.com/minecraft/mc-mods/enders-vein-mine).
2. Place the JAR file into the `mods` folder of your Minecraft installation.
3. Ensure you have the matching mod loader (Fabric or NeoForge) installed.
4. Launch Minecraft and enjoy vein mining!

## Usage
- By default, press **V** while targeting an ore block to mine the entire vein.
- Customize the keybinding and mining radius in the configuration screen (`Mods > Ender's Vein Mine > Config`).
